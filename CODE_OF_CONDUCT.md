# Code of Conduct

## Our Commitment

QuickShow is an open and welcoming project.
We are committed to providing a friendly, safe, and respectful environment for everyone.

---

## Expected Behavior

All contributors are expected to:

* Be respectful and considerate
* Communicate clearly and constructively
* Accept feedback gracefully
* Help others learn and grow
* Focus on improving the project

---

## Unacceptable Behavior

The following behaviors will not be tolerated:

* Harassment, discrimination, or abusive language
* Personal attacks or insults
* Spam or irrelevant contributions
* Any behavior that harms the community

---

## Enforcement

If any unacceptable behavior is reported:

* It will be reviewed carefully
* Appropriate action will be taken (warning, removal, or ban)

---

## Reporting Issues

If you experience or witness inappropriate behavior:

* Report it privately to the project maintainer
* Provide as much context as possible

---

## Scope

This Code of Conduct applies to:

* GitHub discussions
* Issues & pull requests
* Any project-related communication

---

## Note

QuickShow is a **portfolio project**, but it follows professional standards.
All contributors are expected to maintain code quality and respectful collaboration.

---

## Final Note

Be kind. Be respectful. Build something meaningful together
